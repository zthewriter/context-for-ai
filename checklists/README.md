# Checklists

The following table lists each checklist and what to use it for:

| Checklist | Use it to |
|---|---|
| [Site agent readiness](site-agent-readiness.md) | Check that AI agents can find, fetch, and read your docs site: `robots.txt`, `llms.txt`, Markdown versions, and the Agent-Friendly Documentation Spec |
| [Page AI readiness](page-ai-readiness.md) | Score one page on whether it works when AI reads it as passages |
| [AI system docs completeness](ai-system-docs-completeness.md) | Check that an AI system's docs answer what every audience needs |
