# Internal engineering

This folder is for engineers and writers who document internal codebases and
services, the ones only their own company depends on. Internal docs are now read by
coding agents working in the same repositories, so the decisions, boundaries, and
procedures that used to live in people's heads need to be written where an agent
can find them. This folder holds no templates of its own. It indexes the templates
this role uses most.
