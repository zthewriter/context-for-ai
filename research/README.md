# Research

This folder holds the evidence behind the role pages in this repository: how the
job-posting samples were gathered, the coded results of each round, and a log for
practitioner interviews.

## What is here

The following table lists each file and folder:

| Path | What it holds |
|---|---|
| [persona-method.md](persona-method.md) | How each job-posting sample is gathered and coded |
| [2026-10/](2026-10/README.md) | The coded duty counts from the October 2026 round |
| [interviews.md](interviews.md) | A structured log for practitioner interviews |

## How often the sample repeats

The job-posting sample repeats quarterly, with the same method. Each round gets its
own dated folder, named `YYYY-MM`, so earlier rounds stay comparable and nothing is
overwritten.

## What this folder never holds

No round stores employer names, posting links, or posting text. Openings close and
pages change, and a posting is an employer's words, not ours to republish. Each
round holds only the coded counts.
