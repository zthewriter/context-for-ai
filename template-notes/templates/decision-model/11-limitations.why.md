# Why the Limitations template exists (DEC-11)

This note explains why the [Limitations template](../../../templates/decision-model/11-limitations.md) exists. It lives outside the template folders, so copying a set does not copy it.

## What demand created this document

Readers of a decision-model system need to know when not to rely on it.

## What the classic document misses

A classic known-issues page lists bugs that will be fixed. This template lists limits that come from how the system works and will not go away with a patch.

## What goes wrong without it

Readers find each limit by being hurt by it, and stop trusting the system altogether.
