# Why the Session handoff note template exists (HRN-11)

This note explains why the [Session handoff note template](../../../templates/harness/session-handoff-note.md) exists. It lives outside the template folders, so copying a set does not copy it.

## What demand created this document

Long tasks span several agent sessions, and each new session starts with no memory of the last.

## What the classic document misses

A classic shift handover note is written for a colleague who can ask questions. It rarely lists what was tried and failed, which is what stops the next session repeating it.

## What goes wrong without it

The next session redoes finished work or retries an approach that already failed.
