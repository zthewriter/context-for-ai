# Why the Retrieval rules spec template exists (HRN-04)

This note explains why the [Retrieval rules spec template](../../../templates/harness/retrieval-rules-spec.md) exists. It lives outside the template folders, so copying a set does not copy it.

## What demand created this document

Search sometimes ranks the wrong source first, and teams add rules to correct it.

## What the classic document misses

There is no classic equivalent. Rules are configuration, and without a test question for each, nobody knows when one stops working.

## What goes wrong without it

Rules pile up, conflict, and quietly stop firing.
