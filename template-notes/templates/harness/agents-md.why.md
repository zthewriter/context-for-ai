# Why the AGENTS.md template exists (HRN-01)

This note explains why the [AGENTS.md template](../../../templates/harness/agents-md.md) exists. It lives outside the template folders, so copying a set does not copy it.

## What demand created this document

Coding agents now open a repository before any person on the team explains it, and they act on whatever they find first.

## What the classic document misses

A classic CONTRIBUTING.md is written for a person who reads once and asks questions. It does not state boundaries as rules an agent can apply, and it copies long docs that cost context on every task.

## What goes wrong without it

Agents run the wrong commands, break conventions review enforces, and touch files nobody meant them to.
