# Why the Context delivery plan template exists (HRN-06)

This note explains why the [Context delivery plan template](../../../templates/harness/context-delivery-plan.md) exists. It lives outside the template folders, so copying a set does not copy it.

## What demand created this document

Documentation now reaches readers through agents, over several channels: MCP servers, APIs, llms.txt, exports, repository files, and skills.

## What the classic document misses

A classic content strategy plans pages and navigation for people. It does not choose a channel per audience or say how anyone observes whether the context was used.

## What goes wrong without it

Teams publish on a channel no one's agent uses, and cannot tell.
