# Why the Memory spec template exists (HRN-05)

This note explains why the [Memory spec template](../../../templates/harness/memory-spec.md) exists. It lives outside the template folders, so copying a set does not copy it.

## What demand created this document

Agents that remember across sessions keep data nobody reviewed, for as long as nobody stops them.

## What the classic document misses

There is no classic equivalent. Memory sits between user data and documentation, and a classic data policy does not say which wins when memory and the sources disagree.

## What goes wrong without it

The agent repeats an old answer from memory after the docs changed, or keeps personal data with no expiry.
