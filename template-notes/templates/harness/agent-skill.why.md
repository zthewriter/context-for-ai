# Why the Agent skill template exists (HRN-02)

This note explains why the [Agent skill template](../../../templates/harness/agent-skill.md) exists. It lives outside the template folders, so copying a set does not copy it.

## What demand created this document

Teams repeat the same procedures with agents and re-explain them every session.

## What the classic document misses

A classic standard operating procedure is written for a person. It lacks the description an agent reads to decide whether to load it, and it rarely says how each step shows success.

## What goes wrong without it

Agents improvise a procedure the team already settled, a little differently each time.
