# Why the Context changelog template exists (HRN-12)

This note explains why the [Context changelog template](../../../templates/harness/context-changelog.md) exists. It lives outside the template folders, so copying a set does not copy it.

## What demand created this document

Answers change when sources, rules, or instructions change, and people need to find out why.

## What the classic document misses

A classic changelog records product changes. Context changes are invisible to users and often unrecorded, and a classic changelog has no place for the measured effect.

## What goes wrong without it

Answer quality drops and nobody can match it to the change that caused it.
