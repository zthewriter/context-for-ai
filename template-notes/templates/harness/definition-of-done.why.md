# Why the Definition of done template exists (HRN-09)

This note explains why the [Definition of done template](../../../templates/harness/definition-of-done.md) exists. It lives outside the template folders, so copying a set does not copy it.

## What demand created this document

Agents report work as finished. A person needs a fixed list of checks to decide whether it is.

## What the classic document misses

A classic definition of done is a team agreement read by people. It rarely names a command or evidence for each check, which is what an agent can act on.

## What goes wrong without it

Agents report work as done that fails review, or skip a failing check to finish.
