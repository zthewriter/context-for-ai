# Why the RAG concepts overview template exists (RAG-03)

This note explains why the [RAG concepts overview template](../../../templates/rag/03-concepts-overview.md) exists. It lives outside the template folders, so copying a set does not copy it.

## What demand created this document

Every page about a RAG system needs the same few terms, and readers arrive from many entry points.

## What the classic document misses

A classic concept page explains a feature. This template defines the technology once, links to its canonical source, and ends with how the product applies it, so other pages can link here instead of re-explaining.

## What goes wrong without it

Each page defines the same term differently, and an agent that retrieves one page gets a definition that contradicts another.
