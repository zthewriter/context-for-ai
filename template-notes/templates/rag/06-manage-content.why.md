# Why the Manage content template exists (RAG-06)

This note explains why the [Manage content template](../../../templates/rag/06-manage-content.md) exists. It lives outside the template folders, so copying a set does not copy it.

## What demand created this document

Content owners need to know exactly what a RAG system answers from, and support needs it to judge an answer.

## What the classic document misses

A classic admin guide covers settings. This template treats the content sources as the main configuration, because what is indexed decides what can be answered.

## What goes wrong without it

Nobody can say why the system did or did not know something, so every wrong answer becomes an engineering investigation.
