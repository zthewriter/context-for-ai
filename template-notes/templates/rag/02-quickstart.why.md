# Why the RAG quick start template exists (RAG-02)

This note explains why the [RAG quick start template](../../../templates/rag/02-quickstart.md) exists. It lives outside the template folders, so copying a set does not copy it.

## What demand created this document

Developers evaluating a RAG system decide in minutes whether to keep going, so the first working request has to come fast.

## What the classic document misses

A classic quick start shows a request and a response. This template adds the concepts the reader is about to use and a short architecture, because an AI response is not self-explanatory the way a status code is.

## What goes wrong without it

Readers get a response they cannot interpret and conclude the product does not work.
