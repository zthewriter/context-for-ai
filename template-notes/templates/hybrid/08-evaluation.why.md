# Why the Evaluation template exists (HYB-08)

This note explains why the [Evaluation template](../../../templates/hybrid/08-evaluation.md) exists. It lives outside the template folders, so copying a set does not copy it.

## What demand created this document

Teams shipping a hybrid system need a shared definition of good enough, and buyers ask how quality is measured.

## What the classic document misses

A classic test plan checks that features work. This template measures how often results are right, states the method beside every number, and names the result that blocks a release.

## What goes wrong without it

Each change is judged by whoever tried it last, and quality drifts without anyone noticing.
