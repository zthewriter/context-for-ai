# Why the Hybrid concepts template exists (HYB-02)

This note explains why the [Hybrid concepts template](../../../templates/hybrid/02-concepts.md) exists. It lives outside the template folders, so copying a set does not copy it.

## What demand created this document

Teams building a hybrid system need the core terms defined once, in one place other pages can link to.

## What the classic document misses

A classic concept page explains a feature. This template explains a pattern of components and when to choose it, because the choice of pattern decides what can go wrong.

## What goes wrong without it

Readers cannot tell which pattern their system follows, so they cannot predict its failures.
