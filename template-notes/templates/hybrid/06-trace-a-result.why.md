# Why the Trace a result template exists (HYB-06)

This note explains why the [Trace a result template](../../../templates/hybrid/06-trace-a-result.md) exists. It lives outside the template folders, so copying a set does not copy it.

## What demand created this document

Support and engineers need to explain a single result after the fact.

## What the classic document misses

A classic troubleshooting guide starts from an error. This template starts from a result someone questioned and follows it back through each part's trace.

## What goes wrong without it

Questioned results cannot be explained, so the team cannot tell a bug from an acceptable judgment call.
