# Why the Overview template exists (MCP-01)

This note explains why the [Overview template](../../../templates/mcp-server/01-overview.md) exists. It lives outside the template folders, so copying a set does not copy it.

## What demand created this document

Developers decide in minutes whether to connect a server, and agents read the server description to decide whether it is relevant at all.

## What the classic document misses

A classic product overview sells the product. It does not list the tools, resources, and prompts the server exposes, which is what both readers need to decide.

## What goes wrong without it

A server gets connected for a task it cannot do, or ignored for one it can.
