# Why the Evaluation template exists (MCP-11)

This note explains why the [Evaluation template](../../../templates/mcp-server/11-evaluation.md) exists. It lives outside the template folders, so copying a set does not copy it.

## What demand created this document

A change to a tool description can change which tool agents call, and only a fixed question set shows it.

## What the classic document misses

A classic test plan checks that a call returns the right data. It does not check that an agent chooses the call, which is a separate measure.

## What goes wrong without it

A reworded description ships and tool choice drops without anyone measuring it.
