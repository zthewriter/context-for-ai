# Why the Resources reference template exists (MCP-05)

This note explains why the [Resources reference template](../../../templates/mcp-server/05-resources-reference.md) exists. It lives outside the template folders, so copying a set does not copy it.

## What demand created this document

Resources are context an agent reads without asking a question, so readers need to know what each one holds and how fresh it is.

## What the classic document misses

A classic content inventory lists pages. It does not state freshness, and an agent that reads stale context answers confidently from it.

## What goes wrong without it

Agents answer from content that changed since it was read.
