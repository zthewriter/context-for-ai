# Why the Prompts reference template exists (MCP-06)

This note explains why the [Prompts reference template](../../../templates/mcp-server/06-prompts-reference.md) exists. It lives outside the template folders, so copying a set does not copy it.

## What demand created this document

Prompts are chosen by people from a menu in their client, so each one needs a sentence that tells a person when to use it.

## What the classic document misses

There is no classic equivalent. Prompts are a protocol feature with arguments, and an undocumented prompt is a menu item nobody chooses.

## What goes wrong without it

Prompts go unused, or are used with the wrong arguments.
