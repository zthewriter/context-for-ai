# Why the SDK quick start template exists (CLS-09)

This note explains why the [SDK quick start template](../../../templates/classic/sdk-quickstart.md) exists. It lives outside the template folders, so copying a set does not copy it.

## What demand created this document

Developers ask agents to set up an SDK, and the agent follows the quick start literally.

## What the classic document misses

A classic quick start shows install and a call. The upgrade adds a "Tested with" date and versions and a verify step, because an agent cannot tell a stale example from a current one.

## What goes wrong without it

An agent follows an outdated quick start and installs a version with a different interface.
