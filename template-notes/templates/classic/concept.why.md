# Why the Concept template exists (CLS-14)

This note explains why the [Concept template](../../../templates/classic/concept.md) exists. It lives outside the template folders, so copying a set does not copy it.

## What demand created this document

Agents answer "what is" and "why" questions from concept pages.

## What the classic document misses

A classic concept page builds up to a definition. The upgrade puts the definition with the term in the first sentence and uses one term per idea, so the first retrieved passage answers the question.

## What goes wrong without it

An agent answers from a passage that uses a synonym and never states the definition.
