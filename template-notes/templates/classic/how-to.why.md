# Why the How-to guide template exists (CLS-13)

This note explains why the [How-to guide template](../../../templates/classic/how-to.md) exists. It lives outside the template folders, so copying a set does not copy it.

## What demand created this document

Readers and agents arrive with one goal and want the shortest path to it.

## What the classic document misses

A classic how-to often covers related tasks on one page. The upgrade enforces one goal per page and puts it in the title and first sentence, so a retrieved page states what it does.

## What goes wrong without it

An agent follows the steps for a related task on the same page.
