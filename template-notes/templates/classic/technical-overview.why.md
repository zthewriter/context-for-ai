# Why the Technical overview template exists (CLS-02)

This note explains why the [Technical overview template](../../../templates/classic/technical-overview.md) exists. It lives outside the template folders, so copying a set does not copy it.

## What demand created this document

New engineers, partners, and agents all need a one-page picture of a system before the details.

## What the classic document misses

A classic overview describes the parts in flowing prose. The upgrade gives each part its own section, so a retrieved passage names the part it describes instead of saying "it".

## What goes wrong without it

A retrieved paragraph about one part reads as if it described the whole system.
