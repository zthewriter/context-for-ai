# Why the Release notes template exists (CLS-16)

This note explains why the [Release notes template](../../../templates/classic/release-notes.md) exists. It lives outside the template folders, so copying a set does not copy it.

## What demand created this document

Agents answer "what changed" questions and decide whether code needs updating.

## What the classic document misses

Classic release notes list changes in any order. The upgrade puts breaking changes first with the required action, and puts the version and date in each heading, so a retrieved section says which release it describes.

## What goes wrong without it

An agent applies advice from an old release to the current one.
