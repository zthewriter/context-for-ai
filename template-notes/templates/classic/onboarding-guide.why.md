# Why the Onboarding guide template exists (CLS-20)

This note explains why the [Onboarding guide template](../../../templates/classic/onboarding-guide.md) exists. It lives outside the template folders, so copying a set does not copy it.

## What demand created this document

New engineers onboard with a coding agent beside them, and the agent reads the same guide.

## What the classic document misses

A classic onboarding guide is a list of links. The upgrade organizes it by day with a check at the end of each, and records what surprises newcomers, which is knowledge no code contains.

## What goes wrong without it

The new engineer and their agent both learn the same surprise the hard way.
