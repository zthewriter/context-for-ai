# Why the Glossary template exists (CLS-21)

This note explains why the [Glossary template](../../../templates/classic/glossary.md) exists. It lives outside the template folders, so copying a set does not copy it.

## What demand created this document

Agents look up terms one at a time when they meet them.

## What the classic document misses

A classic glossary is a table. The upgrade gives each term its own heading and starts each definition with the term, because a table retrieves as one passage and an agent that searches for one term gets all of them or none.

## What goes wrong without it

An agent misreads a term that has a special meaning in this product.
