# Why the Project README template exists (CLS-01)

This note explains why the [Project README template](../../../templates/classic/project-readme.md) exists. It lives outside the template folders, so copying a set does not copy it.

## What demand created this document

Coding agents now open the README before any other file, so it serves a machine reader as well as a newcomer.

## What the classic document misses

A classic README grows into a long page of mixed facts. The upgrade puts a one-sentence description first, gives each fact its own section, and separates internal from open-source sections, so an agent retrieves the one fact it needs.

## What goes wrong without it

An agent reads a stale or sprawling README, runs the wrong command, and the developer blames the agent.
