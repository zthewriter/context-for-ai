# Why the Troubleshooting template exists (CLS-15)

This note explains why the [Troubleshooting template](../../../templates/classic/troubleshooting.md) exists. It lives outside the template folders, so copying a set does not copy it.

## What demand created this document

Agents diagnose problems from an error message, so troubleshooting pages are searched by symptom.

## What the classic document misses

A classic troubleshooting guide groups problems by component. The upgrade puts the exact error message in the heading and keeps symptom, cause, and fix together, because that is what an agent searches for.

## What goes wrong without it

The fix exists, but the agent never finds it because the heading names a component, not the message.
