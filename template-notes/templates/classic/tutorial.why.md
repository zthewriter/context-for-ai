# Why the Tutorial template exists (CLS-12)

This note explains why the [Tutorial template](../../../templates/classic/tutorial.md) exists. It lives outside the template folders, so copying a set does not copy it.

## What demand created this document

Newcomers still learn by building, and agents now follow tutorials step by step for them.

## What the classic document misses

A classic tutorial is one long narrative. The upgrade makes each step make sense on its own and adds a tested date, so a retrieved step is still correct and still current.

## What goes wrong without it

A retrieved step depends on context from an earlier step the agent never read.
