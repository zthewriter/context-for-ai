# Why the End user guide template exists (AUD-01)

This note explains why the [End user guide template](../../../templates/audience-guides/end-user-guide.md) exists. It lives outside the template folders, so copying a set does not copy it.

## What demand created this document

People who use or are affected by an AI system need to know when to trust a result.

## What the classic document misses

A classic user guide shows how to use features. This upgrade adds how to check a result, what the system cannot do, and what to do when it is wrong.

## What goes wrong without it

Users trust every result equally, including the wrong ones.
