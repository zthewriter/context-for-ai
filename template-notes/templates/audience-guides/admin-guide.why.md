# Why the Admin guide template exists (AUD-02)

This note explains why the [Admin guide template](../../../templates/audience-guides/admin-guide.md) exists. It lives outside the template folders, so copying a set does not copy it.

## What demand created this document

Admins of an AI system manage content, thresholds, and reported mistakes, not only settings.

## What the classic document misses

A classic admin guide covers configuration. This upgrade adds managing what the system answers from and handling a reported mistake.

## What goes wrong without it

Reported mistakes are fixed one at a time, and their cause is never addressed.
