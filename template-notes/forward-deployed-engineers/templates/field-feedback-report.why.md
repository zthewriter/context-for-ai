# Why the Field feedback report template exists (FDE-11)

This note explains why the [Field feedback report template](../../../forward-deployed-engineers/templates/field-feedback-report.md) exists. It lives outside the template folders, so copying a set does not copy it.

## What demand created this document

Forward deployed engineers see what breaks in real use before anyone else does.

## What the classic document misses

A feature request asks for something. This template reports evidence, the workaround and its cost, and how many customers were affected, so the product team can prioritize.

## What goes wrong without it

Every engagement builds the same workaround, and the product never changes.
