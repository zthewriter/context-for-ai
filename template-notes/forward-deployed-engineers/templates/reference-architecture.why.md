# Why the Reference architecture template exists (FDE-02)

This note explains why the [Reference architecture template](../../../forward-deployed-engineers/templates/reference-architecture.md) exists. It lives outside the template folders, so copying a set does not copy it.

## What demand created this document

Customers and engineers need one picture of how the system fits into the customer's environment.

## What the classic document misses

A classic architecture overview describes one system. This template shows the boundary between the customer's systems and yours, and who owns each side.

## What goes wrong without it

Ownership is unclear after launch, and incidents bounce between teams.
