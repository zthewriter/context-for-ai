# Why the Sample and tutorial template exists (FDE-03)

This note explains why the [Sample and tutorial template](../../../forward-deployed-engineers/templates/sample-and-tutorial.md) exists. It lives outside the template folders, so copying a set does not copy it.

## What demand created this document

Customers learn a product fastest from a sample that matches their own use case.

## What the classic document misses

A classic tutorial uses a generic example. This template uses the customer's use case with fake data, and records the date and versions it was tested on.

## What goes wrong without it

The sample breaks on the next release, and the customer's first experience is a failure.
