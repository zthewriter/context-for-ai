# Why the Limitations note template exists (FDE-05)

This note explains why the [Limitations note template](../../../forward-deployed-engineers/templates/limitations-note.md) exists. It lives outside the template folders, so copying a set does not copy it.

## What demand created this document

Customers agree to limits during an engagement, and those agreements need a written record.

## What the classic document misses

A classic known-issues page lists bugs. This template records limits both sides agreed to, so they are not rediscovered as complaints.

## What goes wrong without it

A limit agreed in a meeting becomes a dispute months later.
