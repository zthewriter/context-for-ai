# Why the Field playbook template exists (FDE-01)

This note explains why the [Field playbook template](../../../forward-deployed-engineers/templates/field-playbook.md) exists. It lives outside the template folders, so copying a set does not copy it.

## What demand created this document

Forward deployed engineers repeat the same setup at every customer and need a tested sequence.

## What the classic document misses

A classic implementation guide assumes a standard environment. This template records what changes per customer and what was learned in the field.

## What goes wrong without it

Each engineer rediscovers the same problems at each customer.
