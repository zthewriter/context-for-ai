# Why the Demo script template exists (DVA-02)

This note explains why the [Demo script template](../../../developer-advocates/templates/demo-script.md) exists. It lives outside the template folders, so copying a set does not copy it.

## What demand created this document

Live demos now call networks and models, which fail on stage more often than a local app.

## What the classic document misses

A classic talk outline lists topics. It does not give each step a fallback, or let someone else give the demo.

## What goes wrong without it

A demo stalls on a slow model call, and the message the audience leaves with is that the product does not work.
