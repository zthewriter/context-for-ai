# Why the Verified sample README template exists (DVA-01)

This note explains why the [Verified sample README template](../../../developer-advocates/templates/verified-sample-readme.md) exists. It lives outside the template folders, so copying a set does not copy it.

## What demand created this document

Agents copy quickstarts and samples into users' projects step by step, exactly as written.

## What the classic document misses

A classic sample README does not say when the steps were last run or against which versions, so a reader cannot tell a working sample from a stale one.

## What goes wrong without it

An agent builds a broken project from steps that stopped working two releases ago.
