# Changelog

This file records changes to Context for AI. Newest entries are first.

## Initial public release

Context for AI has three parts:

- **Write for AI:** eight short explainers on how AI systems use your content.
- **Templates:** section templates for documenting RAG, Jev, and hybrid systems. Each
  set includes a tutorial, a quick start, concept pages, and operational pages, plus a
  worked example for a fictional hosting platform, Kestrel. Audience guides, a technical
  design document, a case study, and diagrams complete the set. Start with
  [How to use these templates](templates/how-to-use.md).
- **Checklists:** site agent readiness, page AI readiness, and AI system docs
  completeness.
